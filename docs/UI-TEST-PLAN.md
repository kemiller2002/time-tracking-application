# UI test plan

Automated unit tests cover clock formatting, duration formatting, timestamp-derived elapsed time, pause behavior, and split validation. Expand with API error mapping, queue ordering, conflict comparison, forms, and status labels.

Browser journeys: start/pause/resume/stop; manual six-minute entry; correction; void/restore; split; evidence; review/attestation; monthly exact-value equivalents; offline retry; stale conflict. Viewports: 320, 375, 390, 430, tablet, desktop. Browsers: current iPhone Safari, Chrome, Firefox, Edge.

Accessibility checks combine automated scanning with keyboard, VoiceOver, 200% scaling, focus restoration, reduced motion, forced colors, and contrast review. Performance checks record shell size, layout shift, timer visibility, interaction latency, and queue recovery.

1. `ADR-001` standards-based UI
2. `ADR-002` mobile-first layout
3. `ADR-003` semantic design system
4. `ADR-004` Cloudflare client boundary
5. `ADR-005` secure-cookie authentication
6. `ADR-006` persisted command queue
7. `ADR-007` conservative PWA
8. `ADR-008` timestamp timer reconciliation
9. `ADR-009` small observable store
10. `ADR-010` explicit conflict comparison
11. `ADR-011` signed evidence upload
12. `ADR-012` accessibility baseline
13. `ADR-013` ledger visual interpretation
14. `ADR-014` CSS charts with text equivalents
15. `ADR-015` Shortcut-friendly service commands
